# UI GUIDELINES

Uygulama arayüzü, 2026-2027 dünya standartlarında, premium, minimal, robotik ve gelecek temalı bir SaaS deneyimi sunacaktır.

## Tasarım Prensipleri

- **Cam Efekti (Glassmorphism):** Hafif blur, transparan arka planlar ve ince sınırlar (borders).
- **Renk Paleti:**
  - Ana Renkler: Derin Mavi, Elektrik Mavi, Mor, Beyaz.
  - Yardımcı Elemanlar: Hafif Neon detaylar, Soft Shadow, Blur efektleri.
- **Micro-Interactions (Mikro Etkileşimler):**
  - Sayfa açılışları: 200-300 ms (Fade / Slide).
  - Kart Hover efektleri: 150 ms (Hafif scale / shadow artışı).
  - Modal açılışları: 250 ms.
  - Toast bildirimleri: 180 ms.
- **Erişilebilirlik (WCAG 2.2 AA):**
  - Tam klavye navigasyon desteği.
  - Ekran okuyucular için ARIA etiketleri.
  - Odak halkaları (Focus Ring) ve yüksek renk kontrastı.
  - Responsive Grid (Mobil, Tablet, Masaüstü, Ultra Wide optimizasyonları).

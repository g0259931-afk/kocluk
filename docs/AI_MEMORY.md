# AI MEMORY

## Kısa Dönem Öğrenilenler
- Monorepo yapısı `apps/` ve `packages/` dizinleri üzerinden kuruldu. Root dizinde `package.json` içerisinde workspaces tanımı yapıldı.
- `turbo.json` ve `tsconfig.json` root seviyesinde tüm modüllerin import yollarını destekleyecek şekilde yapılandırıldı.

## Davranış ve Dil Tercihleri
- Kodların içinde mutlaka neden o kodun yazıldığını açıklayan anlamlı Türkçe yorum satırları kullanılacaktır.
- Yazılım kalitesi için dosya satır sınırlarına dikkat edilecek, büyüyen component'lar hemen parçalanacaktır.

## Profil Verileri / Context Notları
- Bu platform premium tasarım diline (Glassmorphism, neon detaylar, blur, soft shadow, robotik minimalizm) ve akıcı mikro etkileşimlere sahip olmalıdır.
